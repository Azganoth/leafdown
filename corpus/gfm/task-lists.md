# Task List Items

## Recognized marker states

- [ ] unchecked
- [x] lowercase checked
- [X] uppercase checked
- [	] tab-as-whitespace unchecked

## Task items can nest

- [x] Parent complete
  - [ ] Child pending
  - [x] Child complete
- [ ] Final parent

## Malformed markers remain ordinary list content

- [] missing marker character
- [y] unsupported marker character
- [x]missing following whitespace
[ ] not a list item
